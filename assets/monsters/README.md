# 3D creature model sources

These textured GLB models are used by `monster-hatch.html`. The site versions are reduced to a web-friendly mesh size and Draco-compressed while retaining their original textures. The rare Crystal Squirrel uses a separate squirrel model with a purple tint and crystal shards along its tail. Rendered PNG previews in `previews/` also show in the game if the browser cannot render WebGL.

The source model pages list these assets as CC0 1.0. The models may be used and adapted in the site. The originals are by Grab3D:

| Site file | Source model |
| --- | --- |
| `dragon.glb` | [Red Dragon](https://grab3d.com/models/creatures/dragon/) |
| `wolf.glb` | [Wolf](https://grab3d.com/models/animals/wolf/) |
| `dinosaur.glb` | [Velociraptor](https://grab3d.com/models/creatures/velociraptor/) |
| `golem.glb` | [Stone Golem](https://grab3d.com/models/creatures/stone-golem/) |
| `squirrel.glb` | [Red Squirrel](https://grab3d.com/models/animals/squirrel/) |
| `crystal-squirrel.glb` | Red Squirrel with a purple tint and added crystal tail shards |
| `lion.glb` | [Lion](https://grab3d.com/models/animals/lion/) |
| `ghost.glb` | [Horror Monster](https://grab3d.com/models/creatures/horror-monster/) |
| `snake.glb` | [Snake](https://grab3d.com/models/animals/snake/) |
| `bird.glb` | [Bald Eagle](https://grab3d.com/models/animals/eagle/) |

Grab3D's [developer and license page](https://grab3d.com/developers/) says published models use CC0 1.0. Three.js and its loaders are included locally under `scripts/vendor/`; their MIT license is in that folder.
